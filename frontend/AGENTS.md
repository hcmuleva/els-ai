Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

## UI Design Rules
- **NEVER USE SINGLE-SIDED ACCENT BORDERS**: Never use single-sided borders (e.g. `borderTopWidth: 4`, thick top colored border line, left accent stripe). It looks unprofessional and AI-generated.
- **Card Styling**: Always use clean uniform borders (`borderWidth: 1`, `borderColor: '#E8ECF4'`), soft shadows, and express accents through inner badges/pills, icon background boxes, and clean typography.
